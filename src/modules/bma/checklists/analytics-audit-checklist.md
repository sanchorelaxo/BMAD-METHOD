# Analytics Audit Checklist

## Tracking Setup

- [ ] Analytics code installed correctly
- [ ] All pages tracked
- [ ] Events firing properly
- [ ] Cross-domain tracking if needed
- [ ] Filters configured

## Goals & Conversions

- [ ] Goals defined and active
- [ ] Conversion tracking working
- [ ] Ecommerce tracking if applicable
- [ ] Funnel visualization set up
- [ ] Attribution model selected

## Data Quality

- [ ] No duplicate tracking
- [ ] Bot traffic filtered
- [ ] Internal traffic excluded
- [ ] Referral spam blocked
- [ ] Data sampling understood

## Reporting Setup

- [ ] Custom dashboards created
- [ ] Key reports saved
- [ ] Automated reports scheduled
- [ ] Segments defined
- [ ] Annotations used

## Integration

- [ ] Ad platforms connected
- [ ] CRM integrated if applicable
- [ ] Search Console linked
- [ ] Other tools connected
- [ ] Data flowing correctly

## Compliance

- [ ] Privacy policy updated
- [ ] Cookie consent implemented
- [ ] Data retention set
- [ ] User deletion process
- [ ] GDPR/CCPA compliant
