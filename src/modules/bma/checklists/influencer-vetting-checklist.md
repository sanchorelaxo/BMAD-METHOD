# Influencer Vetting Checklist

## Audience Quality

- [ ] Follower count appropriate
- [ ] Engagement rate healthy (2%+)
- [ ] Audience demographics match
- [ ] Geographic alignment
- [ ] Authentic followers (not bots)

## Content Quality

- [ ] Content style fits brand
- [ ] Production quality acceptable
- [ ] Posting frequency consistent
- [ ] Authentic voice
- [ ] Previous brand work quality

## Brand Safety

- [ ] No controversial content
- [ ] Values align with brand
- [ ] No competitor conflicts
- [ ] Professional reputation
- [ ] Clean comment sections

## Performance History

- [ ] Previous campaign results
- [ ] Testimonials from brands
- [ ] Case studies available
- [ ] Reliable and responsive
- [ ] Meets deadlines

## Practical Considerations

- [ ] Within budget
- [ ] Available for timeline
- [ ] Open to collaboration
- [ ] Clear on deliverables
- [ ] Contract-ready
