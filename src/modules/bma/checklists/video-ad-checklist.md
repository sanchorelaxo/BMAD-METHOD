# Video Ad Checklist

## Hook (First 5 Seconds)

- [ ] Grabs attention immediately
- [ ] Brand visible before skip button
- [ ] Pattern interrupt or curiosity gap
- [ ] Relevant to target audience
- [ ] Sets up the rest of the ad

## Message Clarity

- [ ] Single clear message
- [ ] Benefits over features
- [ ] Problem-solution structure
- [ ] Easy to understand without sound
- [ ] Appropriate pacing

## Visual Quality

- [ ] High production value
- [ ] Brand colors/elements present
- [ ] Text readable on mobile
- [ ] Engaging visuals throughout
- [ ] Thumbnail is compelling

## Audio

- [ ] Clear voiceover/dialogue
- [ ] Music supports message
- [ ] Captions included
- [ ] Sound levels balanced
- [ ] Works with sound off

## Call-to-Action

- [ ] CTA is clear and specific
- [ ] Appears at right moment
- [ ] Easy to act on
- [ ] URL/destination correct
- [ ] Urgency if appropriate

## Technical Specs

- [ ] Correct aspect ratio
- [ ] File size optimized
- [ ] Duration within limits
- [ ] Resolution appropriate
- [ ] Format compatible
