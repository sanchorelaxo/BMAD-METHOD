# Engagement Checklist

## Content Quality

- [ ] Provides clear value
- [ ] Relevant to audience
- [ ] Timely and current
- [ ] Unique perspective
- [ ] Well-formatted for platform

## Engagement Hooks

- [ ] Opens with hook/question
- [ ] Encourages comments
- [ ] Asks for opinions
- [ ] Includes save-worthy content
- [ ] Share-worthy elements

## Community Building

- [ ] Responds to comments promptly
- [ ] Asks follow-up questions
- [ ] Thanks engaged users
- [ ] Highlights user contributions
- [ ] Creates conversation

## Platform Optimization

- [ ] Posted at optimal time
- [ ] Hashtags researched
- [ ] Tagged relevant accounts
- [ ] Cross-promoted appropriately
- [ ] Format matches platform

## Call-to-Action

- [ ] Clear next step
- [ ] Easy to complete
- [ ] Value is evident
- [ ] Urgency if appropriate
- [ ] Link works correctly
