# Technical SEO Checklist

## Crawlability

- [ ] Robots.txt properly configured
- [ ] XML sitemap submitted
- [ ] No crawl errors in Search Console
- [ ] Important pages not blocked
- [ ] Crawl budget optimized

## Indexation

- [ ] Key pages indexed
- [ ] No duplicate content issues
- [ ] Canonical tags implemented
- [ ] Noindex on thin/duplicate pages
- [ ] Index coverage reviewed

## Site Speed

- [ ] Core Web Vitals passing
- [ ] Page load under 3 seconds
- [ ] Images optimized
- [ ] CSS/JS minified
- [ ] Caching enabled

## Mobile Optimization

- [ ] Mobile-friendly design
- [ ] Responsive layout
- [ ] Touch elements sized properly
- [ ] No horizontal scrolling
- [ ] Mobile speed optimized

## Security

- [ ] HTTPS enabled
- [ ] SSL certificate valid
- [ ] No mixed content
- [ ] Security headers set
- [ ] No malware warnings

## Structured Data

- [ ] Schema markup implemented
- [ ] No errors in testing tool
- [ ] Appropriate schema types
- [ ] Rich results eligible
- [ ] Breadcrumbs marked up

## Site Architecture

- [ ] Logical URL structure
- [ ] Shallow page depth
- [ ] Clear navigation
- [ ] Internal linking strategy
- [ ] Orphan pages addressed
