# Content Quality Checklist

## Headline & Hook

- [ ] Headline grabs attention immediately
- [ ] Promise is clear and compelling
- [ ] Target audience is addressed
- [ ] Curiosity or urgency is created
- [ ] Keywords included naturally

## Structure & Flow

- [ ] Opening hook engages within first paragraph
- [ ] Logical flow from intro to conclusion
- [ ] Subheadings break up content effectively
- [ ] Paragraphs are scannable (3-4 sentences max)
- [ ] Transitions connect ideas smoothly

## Value & Relevance

- [ ] Addresses specific pain points
- [ ] Provides actionable insights
- [ ] Supports claims with evidence
- [ ] Offers unique perspective or information
- [ ] Delivers on headline promise

## Persuasion Elements

- [ ] Benefits emphasized over features
- [ ] Social proof included where appropriate
- [ ] Objections addressed proactively
- [ ] Emotional triggers used effectively
- [ ] Credibility established

## Call-to-Action

- [ ] CTA is clear and specific
- [ ] Action verb leads the CTA
- [ ] Value of taking action is clear
- [ ] CTA placement is strategic
- [ ] Urgency or scarcity if appropriate

## SEO Optimization

- [ ] Primary keyword in title
- [ ] Keywords in first 100 words
- [ ] Meta description is compelling
- [ ] Internal links included
- [ ] Image alt text optimized

## Brand Consistency

- [ ] Voice matches brand guidelines
- [ ] Tone appropriate for audience
- [ ] Terminology is consistent
- [ ] Visual style aligns with brand
- [ ] Messaging supports brand positioning
