# E-commerce Audit Checklist

## Product Pages

- [ ] High-quality images
- [ ] Compelling descriptions
- [ ] Clear pricing
- [ ] Stock availability shown
- [ ] Reviews displayed

## Navigation & Search

- [ ] Easy category navigation
- [ ] Search works well
- [ ] Filters functional
- [ ] Breadcrumbs present
- [ ] Mobile navigation smooth

## Cart Experience

- [ ] Easy add to cart
- [ ] Cart easily accessible
- [ ] Edit quantities simple
- [ ] Saved cart functionality
- [ ] Cross-sell suggestions

## Checkout Process

- [ ] Guest checkout available
- [ ] Minimal form fields
- [ ] Progress indicator
- [ ] Multiple payment options
- [ ] Security badges visible

## Trust & Credibility

- [ ] SSL certificate active
- [ ] Return policy clear
- [ ] Shipping info transparent
- [ ] Contact info visible
- [ ] Reviews/testimonials shown

## Performance

- [ ] Fast page load
- [ ] Mobile optimized
- [ ] No broken links
- [ ] Images optimized
- [ ] Checkout reliable
