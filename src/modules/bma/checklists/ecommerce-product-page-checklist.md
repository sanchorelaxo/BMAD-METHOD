# E-commerce Product Page Checklist

## Product Information

- [ ] Title is descriptive and keyword-rich
- [ ] Description highlights benefits
- [ ] Features listed clearly
- [ ] Specifications complete
- [ ] Size/dimension information accurate

## Visual Assets

- [ ] Multiple high-quality images
- [ ] Zoom functionality works
- [ ] 360° view if applicable
- [ ] Video demonstration included
- [ ] Lifestyle images show context

## Pricing & Availability

- [ ] Price displayed prominently
- [ ] Sale/discount clearly shown
- [ ] Stock status visible
- [ ] Shipping cost/time indicated
- [ ] Payment options displayed

## Trust & Social Proof

- [ ] Customer reviews displayed
- [ ] Star rating visible
- [ ] Review count shown
- [ ] User photos if available
- [ ] Trust badges present

## Call-to-Action

- [ ] Add to cart button prominent
- [ ] Buy now option available
- [ ] Wishlist/save option
- [ ] Quantity selector works
- [ ] Size/variant selector clear

## Cross-Sell & Upsell

- [ ] Related products shown
- [ ] Frequently bought together
- [ ] Bundle options if applicable
- [ ] Upgrade options clear
- [ ] Recently viewed products

## Technical & SEO

- [ ] Page loads quickly
- [ ] Mobile-optimized
- [ ] Schema markup implemented
- [ ] Meta title/description optimized
- [ ] Canonical URL set
