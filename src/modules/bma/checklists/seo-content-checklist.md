# SEO Content Checklist

## Keyword Strategy

- [ ] Primary keyword identified
- [ ] Secondary keywords mapped
- [ ] Search intent understood
- [ ] Keyword difficulty assessed
- [ ] Competitor content analyzed

## On-Page Optimization

- [ ] Primary keyword in title tag
- [ ] Keyword in first 100 words
- [ ] Keyword in H1 heading
- [ ] Keywords in subheadings naturally
- [ ] Keyword density appropriate (1-2%)

## Meta Elements

- [ ] Title tag under 60 characters
- [ ] Meta description under 160 characters
- [ ] Meta description includes CTA
- [ ] URL is short and descriptive
- [ ] URL includes primary keyword

## Content Structure

- [ ] H1 used only once
- [ ] H2-H6 hierarchy logical
- [ ] Paragraphs are scannable
- [ ] Bullet points for lists
- [ ] Table of contents for long content

## Internal Linking

- [ ] Links to relevant internal pages
- [ ] Anchor text is descriptive
- [ ] Links add value for reader
- [ ] No orphan pages created
- [ ] Link equity distributed well

## Technical Elements

- [ ] Images optimized for size
- [ ] Alt text includes keywords naturally
- [ ] Schema markup implemented
- [ ] Page loads under 3 seconds
- [ ] Mobile-friendly design

## E-A-T Signals

- [ ] Author expertise demonstrated
- [ ] Sources cited where appropriate
- [ ] Content is comprehensive
- [ ] Information is accurate and current
- [ ] Trust signals present
