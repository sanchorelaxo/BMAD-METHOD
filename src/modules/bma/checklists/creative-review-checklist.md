# Creative Review Checklist

## Brand Alignment

- [ ] Logo used correctly
- [ ] Colors match brand palette
- [ ] Typography is on-brand
- [ ] Imagery style consistent
- [ ] Voice and tone appropriate

## Design Quality

- [ ] Visual hierarchy clear
- [ ] Layout is balanced
- [ ] White space used well
- [ ] Text is readable
- [ ] Images are high quality

## Message Clarity

- [ ] Main message is clear
- [ ] CTA is prominent
- [ ] Copy is concise
- [ ] No jargon or confusion
- [ ] Benefits are evident

## Technical Specs

- [ ] Correct dimensions
- [ ] Resolution appropriate
- [ ] File format correct
- [ ] Color mode right (RGB/CMYK)
- [ ] Bleed/margins correct

## Platform Optimization

- [ ] Sized for platform
- [ ] Mobile-friendly
- [ ] Load time acceptable
- [ ] Accessibility considered
- [ ] Platform guidelines met

## Legal & Compliance

- [ ] Rights cleared for assets
- [ ] Disclaimers included
- [ ] Trademark usage correct
- [ ] No copyright issues
- [ ] Regulatory compliance
