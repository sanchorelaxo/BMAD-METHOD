# YouTube Optimization Checklist

## Title Optimization

- [ ] Primary keyword included
- [ ] Under 60 characters
- [ ] Compelling and clickable
- [ ] Accurately represents content
- [ ] Numbers or brackets if appropriate

## Thumbnail

- [ ] High contrast colors
- [ ] Readable text (3 words max)
- [ ] Face with emotion if applicable
- [ ] Consistent with brand
- [ ] Stands out in search results

## Description

- [ ] First 2 lines hook viewer
- [ ] Keywords in first 150 characters
- [ ] Timestamps included
- [ ] Links to relevant content
- [ ] CTA included

## Tags & Metadata

- [ ] Primary keyword as first tag
- [ ] Mix of broad and specific tags
- [ ] Competitor video tags researched
- [ ] Category correctly selected
- [ ] Language/location set

## Engagement Elements

- [ ] End screen configured
- [ ] Cards added at key moments
- [ ] Subscribe reminder included
- [ ] Comment prompt in video
- [ ] Playlist assignment

## Technical Quality

- [ ] 1080p minimum resolution
- [ ] Good audio quality
- [ ] Captions/subtitles added
- [ ] Chapters/timestamps work
- [ ] Mobile viewing tested
