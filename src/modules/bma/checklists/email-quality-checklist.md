# Email Quality Checklist

## Subject Line

- [ ] Under 50 characters for mobile
- [ ] Creates curiosity or urgency
- [ ] Personalization token if appropriate
- [ ] Avoids spam trigger words
- [ ] A/B test variant prepared

## Preview Text

- [ ] Complements subject line
- [ ] Adds value, not redundancy
- [ ] Under 90 characters
- [ ] Entices to open

## Email Structure

- [ ] Single clear objective
- [ ] Scannable layout with headers
- [ ] Mobile-responsive design
- [ ] Images have alt text
- [ ] Text-to-image ratio appropriate

## Copy Quality

- [ ] Opening hook is compelling
- [ ] Benefits clearly stated
- [ ] Personalization used effectively
- [ ] Tone matches brand voice
- [ ] Grammar and spelling verified

## Call-to-Action

- [ ] Single primary CTA
- [ ] Button text is action-oriented
- [ ] CTA visible without scrolling
- [ ] Link destination is correct
- [ ] Secondary CTA if appropriate

## Deliverability

- [ ] From name is recognizable
- [ ] Reply-to address monitored
- [ ] Unsubscribe link present
- [ ] Physical address included
- [ ] SPF/DKIM configured

## Testing

- [ ] Tested across email clients
- [ ] Links verified working
- [ ] Personalization tokens tested
- [ ] Rendering checked on mobile
- [ ] Spam score checked
