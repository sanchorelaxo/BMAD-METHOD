# On-Page SEO Checklist

## Title Tag

- [ ] Primary keyword included
- [ ] Under 60 characters
- [ ] Unique across site
- [ ] Compelling for clicks
- [ ] Brand included if space

## Meta Description

- [ ] Under 160 characters
- [ ] Includes primary keyword
- [ ] Contains call-to-action
- [ ] Unique and compelling
- [ ] Accurately describes content

## URL Structure

- [ ] Short and descriptive
- [ ] Includes target keyword
- [ ] Uses hyphens not underscores
- [ ] No unnecessary parameters
- [ ] Lowercase letters only

## Header Tags

- [ ] Single H1 with keyword
- [ ] Logical H2-H6 hierarchy
- [ ] Keywords in subheadings
- [ ] Descriptive and useful
- [ ] Not keyword stuffed

## Content Quality

- [ ] Comprehensive coverage
- [ ] Original and valuable
- [ ] Keyword naturally integrated
- [ ] Proper formatting
- [ ] Updated/current information

## Internal Linking

- [ ] Links to relevant pages
- [ ] Descriptive anchor text
- [ ] Reasonable link count
- [ ] No broken links
- [ ] Supports site structure

## Images

- [ ] Descriptive file names
- [ ] Alt text with keywords
- [ ] Compressed for speed
- [ ] Responsive sizing
- [ ] Lazy loading enabled
