# Conversion Copy Checklist

## Headline

- [ ] Grabs attention immediately
- [ ] Clear benefit or promise
- [ ] Speaks to target audience
- [ ] Creates curiosity or urgency
- [ ] Under 10 words ideally

## Value Proposition

- [ ] Unique benefit clear
- [ ] Differentiation evident
- [ ] Relevant to audience
- [ ] Believable claim
- [ ] Specific, not vague

## Benefits Focus

- [ ] Benefits over features
- [ ] Emotional triggers used
- [ ] Transformation shown
- [ ] Pain points addressed
- [ ] Desires appealed to

## Social Proof

- [ ] Testimonials included
- [ ] Specific results cited
- [ ] Credible sources
- [ ] Relevant to audience
- [ ] Variety of proof types

## Call-to-Action

- [ ] Action verb leads
- [ ] Benefit reinforced
- [ ] Urgency if appropriate
- [ ] Low friction
- [ ] Visually prominent

## Objection Handling

- [ ] Common objections addressed
- [ ] Risk reversal offered
- [ ] FAQ section if needed
- [ ] Guarantees stated
- [ ] Trust signals present

## Readability

- [ ] Scannable format
- [ ] Short paragraphs
- [ ] Bullet points used
- [ ] Subheadings guide reader
- [ ] Mobile-friendly
