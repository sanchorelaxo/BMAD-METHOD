# Product Page Checklist

## Product Information

- [ ] Title is descriptive
- [ ] Price clearly displayed
- [ ] Variants easy to select
- [ ] Stock status shown
- [ ] SKU/product ID visible

## Images & Media

- [ ] Multiple high-quality images
- [ ] Zoom functionality
- [ ] 360° view if applicable
- [ ] Video demonstration
- [ ] Lifestyle context images

## Description & Details

- [ ] Benefits highlighted first
- [ ] Features clearly listed
- [ ] Specifications complete
- [ ] Size/dimension info
- [ ] Materials/ingredients

## Trust Elements

- [ ] Customer reviews visible
- [ ] Star rating displayed
- [ ] Review count shown
- [ ] User photos if available
- [ ] Trust badges present

## Conversion Elements

- [ ] Add to cart prominent
- [ ] Buy now option
- [ ] Wishlist/save feature
- [ ] Quantity selector
- [ ] Shipping estimate

## Cross-Sell

- [ ] Related products shown
- [ ] Frequently bought together
- [ ] Bundle options
- [ ] Recently viewed
- [ ] Complementary items
