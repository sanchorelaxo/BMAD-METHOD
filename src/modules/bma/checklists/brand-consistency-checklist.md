# Brand Consistency Checklist

## Visual Identity

- [ ] Logo used correctly
- [ ] Color palette adhered to
- [ ] Typography matches guidelines
- [ ] Imagery style consistent
- [ ] White space used appropriately

## Voice & Tone

- [ ] Brand voice maintained
- [ ] Tone appropriate for context
- [ ] Terminology consistent
- [ ] Personality comes through
- [ ] Formality level correct

## Messaging

- [ ] Value proposition clear
- [ ] Key messages reinforced
- [ ] Positioning maintained
- [ ] Tagline used correctly
- [ ] Claims are accurate

## Cross-Channel Alignment

- [ ] Consistent across platforms
- [ ] Adapted appropriately per channel
- [ ] Campaign themes unified
- [ ] Timing coordinated
- [ ] Audience experience cohesive

## Quality Standards

- [ ] Professional appearance
- [ ] Error-free content
- [ ] High-quality assets
- [ ] Accessibility considered
- [ ] Mobile experience consistent

## Legal & Compliance

- [ ] Trademark usage correct
- [ ] Copyright respected
- [ ] Disclaimers included
- [ ] Privacy requirements met
- [ ] Industry regulations followed
