# Email Deliverability Checklist

## Authentication

- [ ] SPF record configured
- [ ] DKIM signing enabled
- [ ] DMARC policy set
- [ ] Records verified
- [ ] No authentication failures

## Sender Reputation

- [ ] Dedicated sending IP (if volume)
- [ ] IP properly warmed
- [ ] Domain reputation healthy
- [ ] No blacklist listings
- [ ] Complaint rate under 0.1%

## List Hygiene

- [ ] Double opt-in used
- [ ] Bounces removed promptly
- [ ] Inactive subscribers managed
- [ ] Spam traps avoided
- [ ] Regular list cleaning

## Content Quality

- [ ] No spam trigger words
- [ ] Text-to-image ratio balanced
- [ ] Links are reputable
- [ ] Unsubscribe link present
- [ ] Physical address included

## Technical Setup

- [ ] Proper HTML formatting
- [ ] Plain text version included
- [ ] Images hosted properly
- [ ] Links not broken
- [ ] Mobile rendering tested

## Monitoring

- [ ] Delivery rates tracked
- [ ] Bounce rates monitored
- [ ] Spam complaints reviewed
- [ ] Engagement metrics healthy
- [ ] Inbox placement tested
