# Paid Ads Checklist

## Campaign Setup

- [ ] Campaign objective aligns with business goal
- [ ] Budget allocated appropriately
- [ ] Schedule and dayparting configured
- [ ] Geographic targeting set correctly
- [ ] Device targeting optimized

## Audience Targeting

- [ ] Target audience clearly defined
- [ ] Custom audiences created
- [ ] Lookalike audiences configured
- [ ] Exclusions set to avoid waste
- [ ] Audience size is appropriate

## Ad Creative

- [ ] Headline stops the scroll
- [ ] Value proposition is clear
- [ ] Visual is high-quality and relevant
- [ ] CTA is specific and compelling
- [ ] Ad copy addresses pain points

## Landing Page Alignment

- [ ] Message matches ad promise
- [ ] Landing page loads quickly
- [ ] Mobile experience is optimized
- [ ] Form is simple and clear
- [ ] Trust elements present

## Tracking & Attribution

- [ ] Conversion tracking installed
- [ ] Pixel/tag firing correctly
- [ ] UTM parameters configured
- [ ] Attribution model selected
- [ ] Goals set in analytics

## Compliance

- [ ] Ad policies reviewed
- [ ] Disclaimers included if required
- [ ] Image text within limits
- [ ] Targeting complies with regulations
- [ ] Landing page meets requirements

## Optimization Prep

- [ ] A/B test variants created
- [ ] Bid strategy selected
- [ ] Negative keywords added (search)
- [ ] Placement exclusions set
- [ ] Performance alerts configured
