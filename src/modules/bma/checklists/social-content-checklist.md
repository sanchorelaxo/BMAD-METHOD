# Social Content Checklist

## Content Strategy

- [ ] Aligns with content pillar/theme
- [ ] Serves target audience needs
- [ ] Supports business objective
- [ ] Fits platform best practices
- [ ] Timing is strategic

## Hook & Engagement

- [ ] Opening line stops the scroll
- [ ] First 3 seconds capture attention (video)
- [ ] Question or statement provokes response
- [ ] Curiosity gap created
- [ ] Value is immediately clear

## Platform Optimization

- [ ] Format optimized for platform
- [ ] Aspect ratio is correct
- [ ] Character limits respected
- [ ] Hashtags researched and relevant
- [ ] Tagging strategy applied

## Visual Quality

- [ ] Image/video is high quality
- [ ] Brand elements consistent
- [ ] Text is readable on mobile
- [ ] Accessibility considered
- [ ] Thumbnail is compelling (video)

## Copy Elements

- [ ] Voice matches brand personality
- [ ] Tone appropriate for platform
- [ ] CTA is clear and actionable
- [ ] Emojis used appropriately
- [ ] Link included if needed

## Engagement Strategy

- [ ] Response plan for comments
- [ ] Cross-promotion planned
- [ ] Engagement prompts included
- [ ] Share-worthy elements present
- [ ] Community guidelines followed

## Scheduling

- [ ] Posted at optimal time
- [ ] Doesn't conflict with other content
- [ ] Part of cohesive content mix
- [ ] Evergreen vs timely considered
- [ ] Follow-up content planned
