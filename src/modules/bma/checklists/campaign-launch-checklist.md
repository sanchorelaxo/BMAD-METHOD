# Campaign Launch Checklist

## Pre-Launch Setup

- [ ] Campaign objectives defined
- [ ] Budget allocated and approved
- [ ] Timeline confirmed
- [ ] Team roles assigned
- [ ] Approval workflow set

## Targeting Configuration

- [ ] Audiences created and saved
- [ ] Geographic targeting set
- [ ] Device targeting configured
- [ ] Dayparting scheduled
- [ ] Exclusions applied

## Creative Assets

- [ ] All ad copy approved
- [ ] Images/videos uploaded
- [ ] Specs meet requirements
- [ ] A/B variants ready
- [ ] Brand guidelines followed

## Tracking Setup

- [ ] Pixels/tags installed
- [ ] Conversion events defined
- [ ] UTM parameters set
- [ ] Attribution configured
- [ ] Test conversions verified

## Landing Pages

- [ ] Pages load quickly
- [ ] Mobile optimized
- [ ] Message matches ads
- [ ] Forms working
- [ ] Thank you pages set

## Final Checks

- [ ] Budget caps set
- [ ] Bid strategy confirmed
- [ ] Schedule verified
- [ ] Notifications enabled
- [ ] Stakeholders informed

## Post-Launch

- [ ] Ads approved and running
- [ ] Initial data flowing
- [ ] No error alerts
- [ ] First day review scheduled
- [ ] Optimization plan ready
