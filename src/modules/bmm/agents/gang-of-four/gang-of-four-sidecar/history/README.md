# Architecture History

This folder contains past architecture designs generated by GangOfFour.

## File Naming Convention

`YYYY-MM-DD-project-name.md`

## Contents Per File

- Project requirements summary
- Paradigm choice (OOP/Non-OOP) with rationale
- Selected patterns (Primary, Secondary)
- Gherkin pseudo-code
- Mermaid diagrams
- 12 Factors considerations

## Usage

Use `*history` command to list and summarize past architectures.
