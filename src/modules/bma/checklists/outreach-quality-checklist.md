# Outreach Quality Checklist

## Personalization

- [ ] Recipient name correct
- [ ] Company/role referenced
- [ ] Recent activity mentioned
- [ ] Genuine connection point
- [ ] Not template-obvious

## Value Proposition

- [ ] Leads with value
- [ ] Clear benefit stated
- [ ] Relevant to recipient
- [ ] Not salesy or pushy
- [ ] Specific, not generic

## Message Quality

- [ ] Concise and scannable
- [ ] Professional tone
- [ ] No spelling/grammar errors
- [ ] Easy to respond to
- [ ] Mobile-friendly length

## Call-to-Action

- [ ] Single clear ask
- [ ] Low commitment
- [ ] Easy to say yes
- [ ] Specific next step
- [ ] Time-bound if appropriate

## Follow-Up Plan

- [ ] Timing appropriate
- [ ] Adds new value
- [ ] Not annoying
- [ ] Different angle
- [ ] Graceful exit option
