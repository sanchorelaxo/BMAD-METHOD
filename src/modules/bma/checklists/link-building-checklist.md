# Link Building Checklist

## Strategy Foundation

- [ ] Link building goals defined
- [ ] Target pages identified
- [ ] Competitor backlinks analyzed
- [ ] Link gap opportunities found
- [ ] Anchor text strategy planned

## Content Assets

- [ ] Linkable assets created
- [ ] Original research/data
- [ ] Comprehensive guides
- [ ] Infographics/visuals
- [ ] Tools or calculators

## Outreach Preparation

- [ ] Prospect list built
- [ ] Contact information gathered
- [ ] Personalization research done
- [ ] Email templates created
- [ ] Follow-up schedule set

## Outreach Execution

- [ ] Personalized emails sent
- [ ] Value proposition clear
- [ ] Follow-ups scheduled
- [ ] Responses tracked
- [ ] Relationships nurtured

## Link Quality

- [ ] Relevant to niche
- [ ] From authoritative sites
- [ ] Natural anchor text
- [ ] Dofollow when possible
- [ ] Not from link farms

## Monitoring

- [ ] New links tracked
- [ ] Lost links monitored
- [ ] Toxic links identified
- [ ] Disavow file updated
- [ ] ROI measured
