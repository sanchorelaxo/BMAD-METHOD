# Brand Compliance Audit Checklist

A comprehensive multi-medium checklist for ensuring brand consistency across all marketing channels.

---

## Visual Identity Compliance

### Logo Usage

- [ ] Correct logo version used for context (primary, secondary, icon)
- [ ] Minimum size requirements met
- [ ] Clear space/exclusion zone maintained
- [ ] Approved color variation used (full color, mono, reversed)
- [ ] No unauthorized modifications or distortions
- [ ] Proper placement and alignment
- [ ] Background contrast sufficient
- [ ] Co-branding rules followed (if applicable)

### Color Palette

- [ ] Primary brand colors used correctly
- [ ] Secondary colors applied appropriately
- [ ] Accent colors used sparingly as intended
- [ ] Color ratios/proportions maintained
- [ ] Contrast requirements met (accessibility)
- [ ] No off-brand or unapproved colors
- [ ] Correct color values (HEX/RGB for digital, CMYK/Pantone for print)
- [ ] Gradient usage follows guidelines

### Typography

- [ ] Primary typeface used for headlines
- [ ] Secondary typeface used for body copy
- [ ] Font weights used appropriately
- [ ] Type hierarchy followed correctly
- [ ] Size scale adhered to
- [ ] Line spacing/leading correct
- [ ] Letter spacing/kerning appropriate
- [ ] Web-safe fallback fonts specified (digital)

### Imagery & Graphics

- [ ] Photography style consistent with brand
- [ ] Illustration style on-brand
- [ ] Icon set used correctly
- [ ] Graphic elements aligned with guidelines
- [ ] Image quality standards met (resolution, clarity)
- [ ] Image treatments consistent (filters, overlays)
- [ ] Stock imagery matches brand aesthetic
- [ ] Infographic style consistent

## Accessibility Compliance

### Visual Accessibility

- [ ] Color contrast ratios meet WCAG AA (4.5:1 text, 3:1 large text)
- [ ] Text size minimums met (16px body recommended)
- [ ] Color not used as sole indicator
- [ ] Focus states clearly visible
- [ ] Animation can be paused/stopped
- [ ] No flashing content (seizure risk)

### Content Accessibility

- [ ] Alt text provided for all images
- [ ] Video captions available
- [ ] Transcripts provided for audio
- [ ] Audio descriptions available (video)
- [ ] Plain language used
- [ ] Reading level appropriate for audience

### Interactive Accessibility

- [ ] Keyboard navigation works
- [ ] Screen reader compatible
- [ ] Form labels present and associated
- [ ] Error messages clear and helpful
- [ ] Touch targets minimum 44x44px
- [ ] Skip navigation available

### Document Accessibility

- [ ] PDF accessibility tags present
- [ ] Heading structure logical
- [ ] Lists properly formatted
- [ ] Table headers defined
- [ ] Link text descriptive (not "click here")

## Issue Severity Levels

- **Critical**: Brand damage risk, legal exposure, immediate fix required
- **High**: Significant inconsistency, customer-facing, fix within 24-48 hours
- **Medium**: Noticeable deviation, fix within 1 week
- **Low**: Minor inconsistency, fix in next update cycle
